# portfolio

### Overview

This is the personal portfolio of Romy (aka Xiao Ro), a 2nd-year Computer Science student at USTHB, showcasing skills in front-end web development and game design. The portfolio highlights projects, technical skills, and the upcoming Legacy Podcast. Built with modern web technologies, it features a responsive design, smooth animations, and a clean user interface.

### Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices with a side navigation menu on mobile.

- **Interactive Animations**: Smooth scrolling, fade-ins, and typing effects.

- **Projects Showcase**: Displays games and web projects with links to GitHub.

- **Contact Form**: Includes a form with toast notification feedback.

- **Resume Download**: Professional resume available for download.

- **Legacy Podcast**: Teaser section for the upcoming podcast.


### Technologies Used

- **Frontend**: HTML5, CSS3 (Tailwind CSS), JavaScript

- **Libraries**: Font Awesome, Toastify.js

- **Tools**: Git, LaTeX (for resume)

- **Other Skills**: Java, Python, C, Assembly, Oracle SQL, JavaFX, Swing, Lua
